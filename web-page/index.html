Visión del Proyecto

Clobster OS es una plataforma distribuida diseñada para la transcodificación y manipulación de archivos multimedia de alto rendimiento. Utilizando un modelo de Master-Worker, el sistema centraliza la gestión de tareas en un nodo Master, el cual distribuye la carga de trabajo hacia una red heterogénea de nodos Workers de forma asíncrona.

Ingeniería Distribuida

El corazón del sistema reside en una cola de mensajes gestionada por Redis, permitiendo que nodos con diferentes capacidades de cómputo, desde procesadores modernos hasta hardware legacy, colaboren en tiempo real. La comunicación se realiza mediante latidos de telemetría que proporcionan visibilidad total sobre el clúster.
